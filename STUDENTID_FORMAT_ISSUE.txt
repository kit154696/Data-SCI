================================================================================
ปัญหา StudentID แสดงเป็นตัวเลข (Scientific Notation) ใน Excel
================================================================================

⚠️  ปัญหาที่พบ:
StudentID เช่น 6000000001 ถูก Excel แสดงเป็น 6.00E+09 หรือ 6000000001

================================================================================
สาเหตุของปัญหา
================================================================================

1. CSV Format
   - StudentID ถูกบันทึกเป็น NUMBER (ตัวเลข) ไม่ใช่ TEXT (ข้อความ)
   - Excel อ่านตัวเลขยาว 10 หลักเป็น scientific notation
   - เช่น: 6000000001 → 6.00E+09

2. Excel Behavior
   - Excel จะพยายามแปลงค่าที่ดูเหมือนตัวเลขเป็น number อัตโนมัติ
   - ตัวเลขยาวๆ จะถูกแสดงแบบย่อ (scientific notation)
   - การ format cell เป็น Text ไม่ช่วย ถ้าเปิดไฟล์ใหม่

3. ผลกระทบ
   - ดูยาก อ่านยาก
   - อาจเกิด precision loss ถ้าตัวเลขยาวมากๆ
   - การ join ข้อมูลอาจมีปัญหา

1. สร้างข้อมูลใหม่
-------------------

เมื่อสร้างข้อมูลใหม่ ใส่ prefix ตั้งแต่ต้น:

```python
# ใน data-cr-test.py หรือสคริปต์สร้างข้อมูล
student_ids = [f'S{str(i).zfill(10)}' for i in range(1, 121)]
# ผลลัพธ์: ['S0000000001', 'S0000000002', ...]

# หรือ
student_ids = [f'S{6000000000 + i}' for i in range(1, 121)]
# ผลลัพธ์: ['S6000000001', 'S6000000002', ...]
```

2. บันทึก CSV
--------------

บังคับให้เป็น string และ quote:

```python
import pandas as pd

# สร้าง DataFrame
df = pd.DataFrame({
    'StudentID': ['S6000000001', 'S6000000002'],
    'Group': [1, 2],
    'GPA': [3.5, 3.2]
})

# บันทึกด้วย quoting
df.to_csv('output.csv', index=False, quoting=1)  # quoting=1 = QUOTE_ALL
```

3. อ่าน CSV
------------

บังคับ dtype เป็น string:

```python
# อ่านโดยบังคับให้ StudentID เป็น string
df = pd.read_csv('file.csv', dtype={'StudentID': str})

# หรือ
df = pd.read_csv('file.csv')
df['StudentID'] = df['StudentID'].astype(str)
```

================================================================================
คำถามที่พบบ่อย (FAQ)
================================================================================

Q: ทำไมต้องเพิ่ม 'S' ด้วย? Quote อย่างเดียวไม่พอหรือ?
A: Quote อย่างเดียวก็แก้ได้ แต่เพิ่ม prefix มีข้อดีมากกว่า:
   - อ่านง่าย รู้ทันทีว่าเป็น Student ID
   - ป้องกัน leading zero หาย
   - เป็นมาตรฐานทั่วไป

Q: ต้องแก้โค้ด student_grade_prediction.py ด้วยไหม?
A: ไม่ต้อง! โค้ดอ่าน StudentID เป็น string อัตโนมัติ

Q: ข้อมูลเดิมที่เป็นตัวเลขจะเสียหรือเปล่า?
A: ไม่เสีย! แค่เพิ่ม 'S' ข้างหน้า:
   6000000001 → S6000000001

Q: ถ้าต้องการเลขเดิมคืนมาทำยังไง?
A: ลบ 'S' ออก:
   ```python
   df['StudentID'] = df['StudentID'].str.replace('S', '')
   ```

Q: ถ้าข้อมูลจริงมี prefix อยู่แล้ว (เช่น 64xxxxxxxx) ต้องทำไหม?
A: ถ้ามี prefix หรือเป็น text อยู่แล้ว ไม่ต้องแก้
   สคริปต์จะตรวจสอบและข้ามอัตโนมัติ
