================================================================================
STUDENT GRADE PREDICTION - PROJECT OVERVIEW
================================================================================

⚠️  IMPORTANT NOTICE:
This project uses SYNTHETIC DATA generated for educational and demonstration
purposes only. The data is NOT real student information. All student IDs,
grades, and attendance records are randomly generated to simulate a realistic
academic dataset.

================================================================================
PROJECT DESCRIPTION
================================================================================

Business Question:
How are students performing academically?

Data Science Question:
Can we use historical data and student learning behaviors to build a machine
learning model that predicts the grades students will receive in the next
semester?

Hypothesis:
Student performance in future semesters is related to Academic Behavioral
Features from their past, and these features can be used in a Machine Learning
model to predict grades in advance for monitoring and identifying at-risk
students.

================================================================================
DATASET DESCRIPTION
================================================================================

The dataset contains attendance and grade information for students taking
3 courses: SJ111777, SJ220777, and S333777.

Total: 7 related tables (CSV files)

1. ID_Group.csv (Student Groups)

2. SJ111777_Attendance15weeks.csv (Attendance for Course 1)

4. SJ220777_Attendance15weeks.csv (Attendance for Course 2)
   - StudentID: Student identifier
   - Week1-Week15: Weekly attendance (1=present, 0=absent)

5. SJ220777_Score.csv (Grades for Course 2)
   - StudentID: Student identifier
   - Tasks(100Points): Task scores (max 100)
   - Quiz(90Points): Quiz scores (max 90)
   - Project(90Points): Project scores (max 90)
   - Midterm(180Points): Midterm exam scores (max 180)
   - Final(180Points): Final exam scores (max 180)

6. S333777_Score.csv (Grades for Course 3)
   - StudentID: Student identifier

7. SJ333777_Attendance15weeks.csv (Attendance for Course 3)
   - StudentID: Student identifier

================================================================================
PROJECT FILES EXPLANATION
================================================================================

PYTHON SCRIPTS:
---------------

1. data-cr-test.py
   Purpose: Generate synthetic student data
   What it does:
   - Creates 120 synthetic student records
   - Generates realistic GPA values (1.5-4.0)
   - Simulates attendance patterns (70-100% attendance rate)
   - Creates scores for all 3 courses with realistic distributions
   - Introduces random missing values (~1%) and duplicates (1-2%)
   - Saves 7 CSV files in dataset/ folder

   Output: All 7 CSV files in dataset/

2. student_grade_prediction.py
   Purpose: Main machine learning pipeline
   What it does:
   - Loads all 7 CSV files
   - Cleans data (removes duplicates, fills missing values)
   - Creates 27 engineered features from raw data:
     * Normalized scores for each course component
     * Average scores across courses
     * Min/max scores
     * Attendance rates for each course
     * Average attendance rate
   - Splits data into train/test sets (80/20)
   - Trains 5 ML models:
     * Linear Regression
     * Ridge Regression
     * Lasso Regression (Best model)
     * Random Forest
     * Gradient Boosting
   - Evaluates models using R², RMSE, MAE, Cross-validation
   - Saves the best model to models/ folder
   - Creates 6 visualization plots

   Output:
   - 6 PNG files in analysis_output/
   - 3 model files in models/

3. data_cleaning_analysis.py
   Purpose: Analyze data quality and cleaning process
   What it does:
   - Loads all 7 CSV files
   - Analyzes missing data patterns
   - Counts duplicate rows
   - Calculates data completeness percentages
   - Creates correlation heatmaps
   - Visualizes before/after cleaning comparison
   - Creates 5 visualization plots

   Output: 5 PNG files in analysis_output/

4. predict_new_students.py
   Purpose: Use trained model to predict grades for new students
   What it does:
   - Loads the saved best model
   - Loads the feature scaler
   - Creates example new student data
   - Makes predictions
   - Shows confidence intervals
   - Identifies at-risk students (predicted score < 60)

   Output: Predictions printed to console

5. generate_report.py
   Purpose: Generate comprehensive markdown report
   What it does:
   - Compiles all analysis results
   - Includes all visualizations
   - Writes detailed findings
   - Creates actionable recommendations

   Output: ANALYSIS_REPORT.md

HELPER FILES:
-------------

6. fix_thai_font.py
   Purpose: Fix Thai font display issues in matplotlib
   What it does:
   - Clears matplotlib font cache
   - Tests different Thai fonts available on system
   - Creates test visualization

   Output: Font test PNG file

7. setup_thai_font_final.py
   Purpose: Configure Thai font for matplotlib (if needed)
   What it does:
   - Loads Thonburi font directly from system
   - Configures matplotlib to use Thai font
   - Creates configuration file

   Output: thai_font_config.py

8. thai_font_config.py
   Purpose: Reusable font configuration
   What it does:
   - Provides font setup code for other scripts
   - Can be imported to enable Thai text in plots

   Note: Currently not used as all plots are in English
