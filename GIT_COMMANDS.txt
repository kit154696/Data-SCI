STEP 4: RENAME BRANCH TO MAIN (if needed)
================================================================================

================================================================================
STEP 5: ADD REMOTE REPOSITORY
================================================================================

git remote add origin https://github.com/kit154696/Data-SCI.git

STEP 6: PUSH TO GITHUB
================================================================================

# If you get an error about divergent branches, force push:
git push -u origin main --force

================================================================================

================================================================================

SUBSEQUENT UPDATES (After initial push)
================================================================================

# After making changes to files:

1. Check what changed:
   git status

2. Add changed files:
   git add .

3. Commit with message:

4. Push to GitHub:
   git push

================================================================================
USEFUL GIT COMMANDS
================================================================================

# View commit history
git log --oneline

# See what changed
git diff

# Undo changes (before commit)
git checkout -- <filename>

# Undo last commit (keep changes)
git reset --soft HEAD~1

# Create a new branch
git checkout -b feature-branch-name

# Switch branches
git checkout main

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "fatal: remote origin already exists"
Solution: git remote remove origin, then add again

Problem: "rejected - non-fast-forward"
Solution: git pull origin main --allow-unrelated-histories
          Then: git push origin main

Problem: "permission denied"
Solution: Check your GitHub authentication
          Use SSH key or Personal Access Token

Problem: Large files (>100MB)
Solution: Add to .gitignore or use Git LFS

Problem: Too many files
Solution: Check .gitignore includes __pycache__/, *.pyc, etc.
